## <AR Ruler 컨텐츠 제작>

### 제목 : AR Ruler

#### 기능 : 해당 물체와의 거리측정 및 줄자 측정
 
1. 카메라로 ar상에서 해당 물체와의 거리를 실시간 측정
2. 특정 물체의 길이를 측정 가능하게 구현.
3. 각도 측정 구현

* AR Plane과 AR Point Cloud를 사용하여 해당 평면을 탐지한다.
* 탐지된 해당 평면과 AR Raycast를 카메라에서 쏘아서 해당 거리와 줄자 및 각도를 측정하도록 한다.
